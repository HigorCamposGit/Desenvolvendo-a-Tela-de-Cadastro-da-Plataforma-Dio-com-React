# 🚀 Projeto Desenvolvendo a Tela de Cadastro da Plataforma Dio com React

---

Projeto desenvolvido como parte dos desafios da **Trilha React** da **[Digital Innovation One (DIO)](https://github.com/digitalinnovationone/trilha-react-desafio-3)**, com foco na construção, estruturação e refinamento de uma aplicação web progressiva (PWA) em React.

---

## 🛠️ O que foi feito no desafio.

O principal objetivo deste desafio foi implementar e estilizar a **página de cadastro (Register)**, além de refatorar e polir componentes essenciais da aplicação para garantir uma experiência de usuário profissional e responsiva. 

Durante o desenvolvimento, implementamos:
* **Página de Cadastro Completa**: Estruturação de formulários utilizando `react-hook-form` e validações robustas com `yup`.
* **Refatoração de Componentes**: Ajustes estruturais e visuais no `Header`, `Feed`, e nos componentes de `Card` para garantir harmonia e consistência visual.
* **Integração com API Mockada**: Configuração de um ambiente local com `json-server` (`db.json`) para simular o cadastro e autenticação de usuários.
* **Padronização de Assets**: Padronização dos avatares utilizando imagens do GitHub CDN e melhorias de cache e PWA via `manifest.json`.

---

## 🎨 Estilização

A estilização foi totalmente construída utilizando **`styled-components`**, permitindo uma arquitetura modular baseada em componentes limpos e reutilizáveis. 

* **Tema Visual**: Dark theme moderno (`#1e1e2c`) alinhado com detalhes em verde neon (`#23DD7A`) e rosa/magenta (`#fa055f`).
* **Tipografia**: Utilização da fonte **Open Sans** para garantir legibilidade e um visual limpo.
* **Layout Responsivo**: Uso avançado de Flexbox para organizar o feed de postagens e o ranking da semana de forma equilibrada.

---

## 💻 Tecnologias Utilizadas

* **React (v18)**.
* **React Router DOM** (Gerenciamento de rotas e navegação).
* **Styled-Components** (Estilização escopada e dinâmica).
* **React Hook Form & Yup** (Gerenciamento de formulários e validação de esquemas).
* **Axios** (Requisições HTTP).
* **JSON Server** (API REST mockada para testes).
